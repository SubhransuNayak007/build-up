# BUILD UP — Elite JEE Productivity OS

> Build the habits that build the topper.

A minimalist, keyboard-first productivity dashboard engineered for serious JEE aspirants. Track every study session, visualize momentum, and never lose a streak again.

## ✦ Features

- **Habit tracking** — tap to mark sessions done; persistent streak counters reward showing up daily.
- **Momentum charts** — weekly & monthly productivity trends powered by Chart.js.
- **Weekly grid** — a 7-day at-a-glance matrix showing exactly which habits slipped and when.
- **JEE timetable** — a fixed weekly schedule (Physics / Chemistry / Math / Biology) always one glance away.
- **Editable tasks** — customize habits, categories and streaks without touching code.
- **JSON export** — own your data; one-click export of your full history.
- **100% offline** — no accounts, no signup, no tracking.

## ✦ Tech

Pure hand-written **HTML + CSS + JavaScript** — no build step, no framework.
Charts: [Chart.js 4](https://www.chartjs.org/). Fonts: Space Grotesk, Space Mono, Inter.

## ✦ Run locally

```bash
git clone https://github.com/SubhransuNayak007/build-up.git
cd build-up
# open index.html in any modern browser
python3 -m http.server 8000   # then visit http://localhost:8000
```

## ✦ Deploy

The entire app is a single static `index.html` file — drop it on any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages, devinapps, etc.).
